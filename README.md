# 판코보드 사전 / Pankoboard Dictionary / パンコボード辞書

한국어 학습자를 위한 일본어 낱말 사전과 일본인 학습자를 위한 한국어 낱말 사전입니다.
Android 키보드 「판코보드」(day.loaweek.pankoboard)의 「사전」 카드에 쓰이는 데이터이고, 누구나 가져다 쓰고 고쳐 쓸 수 있도록 공개합니다.

- 일본어 낱말 34,522개: 한국어 뜻·설명·예문·참고, JLPT 수준(N1~N5), 활용 종류(5단·1단·형용사·する동사)
- 한국어 낱말 22,318개: 일본어 뜻·설명·예문·참고, 수준(初級·中級·上級), 문법 어미 카드(`~`로 시작하는 항목) 포함
- 일본어·한국어의 의성·의태어, 속담, 사자성어, 관용구(일본어 약 4,100개, 한국어 약 4,700개), 한국어 단위·접사·외래어·구어 표현, 한국어 문법 표현 약 100개 포함

한국어 학습자용 일본어 사전 / 일본인 한국어 학습자용 한국어 사전.
日本語を学ぶ韓国語話者向けの日本語辞書と、韓国語を学ぶ日本語話者向けの韓国語辞書です。キーボードアプリ「パンコボード」の辞書カードに使われているデータで、自由に利用・改変できます。

## 파일 / Files

- `glossary.tsv` — 사전 본체 (UTF-8, 탭으로 구분)
- `glossary_tags.tsv` — 일본어·한국어 카드의 종류 표시: `lang<TAB>word<TAB>reading<TAB>tag` (`onom` 의성·의태어, `proverb` 속담, `yoji` 사자성어, `idiom` 관용구)
- `kanji_desc.tsv` — 한자 한 글자 카드의 설명 3,066개 (상용한자 2,136자 + 인명용한자·자주 쓰이는 표외한자 930자)
- `kanji_ko.tsv` — 상용한자 2,136자의 한국식 훈음
- `kanji_extra.tsv` — 상용한자가 아닌 한자 930자의 음독·훈독 (KANJIDIC2에서 가공, 아래 참고)
- `tools/build_kanji_extra.py` — `kanji_extra.tsv`를 만드는 스크립트
- `LICENSE` — CC BY-SA 4.0 전문
- `CREDITS.md` — 출처와 감사

### 열 (glossary.tsv)

`lang<TAB>word<TAB>reading<TAB>kind<TAB>also<TAB>meaning<TAB>note<TAB>example<TAB>example's meaning<TAB>tip<TAB>level`

| 열 | 뜻 |
|----|----|
| lang | `ja` 일본어 낱말(한국어 설명) / `ko` 한국어 낱말(일본어 설명) |
| word | 표제어 |
| reading | 일본어: 한자가 있으면 히라가나 읽기(가나만이면 빈칸). 한국어: 로마자로 한글을 입력하는 표기 |
| kind | 일본어 활용: `v5` 5단동사, `v1` 1단동사, `vk` 来る, `adj` い형용사, `vs` する가 붙는 낱말, 빈칸은 활용 안 함 |
| also | 다른 표기. 한국어 동사·형용사는 `활용형:설명`, 문법 어미(`~…`)는 인식 규칙 |
| meaning, note | 뜻과 설명 (일본어 낱말은 한국어, 한국어 낱말은 일본어). 일본어 속담의 meaning은 `직역 \| 덧붙일 말` 꼴이고 `\|` 앞이 글자 그대로의 번역입니다 |
| example, example's meaning | 예문과 그 번역 |
| tip | 학습자를 위한 참고(비슷한 말과의 차이, 한자 연결 등) |
| level | 일본어 N1~N5 / 한국어 初級·中級·上級 |

`#`으로 시작하는 줄은 머리말(주석)입니다.

| `kanji_desc.tsv` | `한자<TAB>설명` (일본어를 배우는 한국인을 위한 한 줄 설명) |

## 만든 방법 / How it was made

직접 쓴 사전입니다. 기존 사전을 복사하지 않았습니다. 낱말은 주제·품사·실제 문장의 빈도에서 골랐고, 항목마다 AI가 초안을 쓰고, 다른 AI 검수자가 사실(읽기·뜻·예문·한자 대응)을, 또 한 명이 학습자 관점(오해·어색한 문장)을 독립적으로 검수했습니다. 무작위 표본 검수에서 사실 오류는 발견되지 않았지만 원어민의 전수 검수를 거친 것은 아닙니다. 틀린 곳을 발견하시면 이슈나 풀 리퀘스트로 알려 주세요.

한자 설명(`kanji_desc.tsv`)도 같은 방식으로 썼습니다(작성 1회 + 독립 검수 2회). 반면 `kanji_extra.tsv`의 읽기는 KANJIDIC2의 값을 기계적으로 옮긴 것이라 드물게 틀린 읽기가 섞여 있습니다. 검수 중 찾은 12곳은 스크립트에서 고쳤지만 전수 검수는 아닙니다.
